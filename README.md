# Jun Romulo Jarina – Portfolio

Run locally: `npm install` then `npm run dev`. Build: `npm run build`.
Edit all content in `src/data/resumeData.js`. Put your resume at `public/resume.pdf`.

## Deploy to GitHub Pages

1. Create a GitHub repo and push this project to the `main` branch.
2. In the repo: Settings > Pages > Source: **GitHub Actions**.
3. Every push to `main` builds and deploys automatically (see `.github/workflows/deploy.yml`).
4. Your site appears at https://JunRomuloJarina.github.io/<repo-name>/
